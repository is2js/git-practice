# Git 연습 메모

![Git 로고](https://raw.githubusercontent.com/github/explore/main/topics/git/git.png)

**터미널과 Git**을 익히는 *작은 메모 프로젝트*입니다.





## 준비물
- Windows PowerShell과 [Git for Windows](https://git-scm.com/install/windows)
- 메모장 또는 텍스트 편집기

Git이 없다면 위 링크에서 Git for Windows를 설치합니다.







## 파일 안내
| 파일                                 | 내용                |
| ------------------------------------ | ------------------- |
| [note.txt](./note.txt)               | 버전 기록 연습 메모 |
| [branch-note.txt](./branch-note.txt) | 브랜치 작업 메모    |





## 내용 확인하기
이 폴더에서 PowerShell을 열고 메모를 읽습니다.

```powershell
cat .\note.txt
```
